GotiPrep

Competitive Examination Practice & Adaptive Mock Test Platform

GotiPrep is an open-source examination preparation ecosystem engineered to provide students with a distraction-free, realistic examination environment. Built specifically for major national entrance and placement exams, it pairs high-fidelity timer mechanisms with rigorous automated evaluation.

  • Realistic exam simulations tailored for TCS NQT, Banking (IBPS / SBI / RBI), and SSC exams.
  • Real-time sectional timers, negative marking logic, and instant scoring analytics.
  • Categorized question banks covering Quantitative Aptitude, Logical Reasoning, and Verbal Ability.
  • Lightweight responsive architecture, with no interstitial ads or pop-ups during a test.

Kagazly

Cloud Document, PDF Manipulation & File Utilities Suite

Kagazly is a modern online document utility suite engineered to solve common PDF friction without requiring heavyweight desktop software or compromising document confidentiality. By executing PDF manipulations directly inside the client browser, user files never leave their device.

  • Fast client-side PDF merging, page splitting, rotation, and reordering.
  • Lossless document compression and memory footprint reduction.
  • High-quality Image-to-PDF and PDF-to-Image batch conversions.
  • 100% Privacy-guaranteed: zero server file uploads or third-party storage.

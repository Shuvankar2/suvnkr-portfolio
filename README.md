# Shuvankar Debnath | Personal Portfolio

A sleek, responsive, and modern personal portfolio website showcasing my work as a **Web Developer, Video Editor, and Graphic Designer**. 

🌐 **Live URL**: [shuvankar.qzz.io](https://shuvankar.qzz.io)

---

> [!NOTE]
> I designed and built this portfolio website during my **2nd year** of pursuing a B.Tech degree to showcase my professional journey, skills, and creative projects.

---

## 🚀 Features

- **Dynamic Landing Slider**: An automated image background slider with elegant slide transitions showcasing creative backdrops.
- **Interactive Experience Cards**: Clean, toggleable detail cards to highlight professional freelancing and volunteering achievements (e.g. SAE IEM Club).
- **Auto-Updating Footer Copyright**: Fully automated footer copyright year leveraging JavaScript to dynamically reflect the current year.
- **Typed.js Text Animation**: High-end modern typewriter style animation displaying my core areas of expertise on the homepage.
- **Fully Responsive & Responsive Navigation**: Desktop-friendly side-menu overlay drawer and mobile-responsive layouts tailored for all screen sizes.
- **Asset Portability**: Engineered entirely using document-relative path structures so it builds and hosts correctly on both root custom domains and GitHub Pages subfolders.

---

## 🛠️ Technology Stack

- **Structure**: HTML5 (Semantic elements)
- **Styling**: Vanilla CSS3 (Custom scrollbars, HSL color tokens, animations, overlay sidebar)
- **Logic**: Vanilla Javascript (ES6+)
- **Libraries**:
  - [Typed.js](https://github.com/mattboldt/typed.js/) (Animated typing text)
  - [FontAwesome v6](https://fontawesome.com/) (Premium iconography)
- **Hosting**: GitHub Pages with custom CNAME domain configuration
